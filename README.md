# Car Rental Management System

A Car Rental Management System built using ASP.NET Core Web API and SQL Server.

This project is being developed as part of my journey to learn Full Stack Web Development.

## 🚧 Project Status

The project is currently under development.

The Backend has been implemented with the main CRUD APIs and database integration.
The Frontend will be developed after completing my Frontend Web Development learning.
